# サンプルデータセット

このディレクトリには、システムの動作を確認するためのサンプルデータが含まれています。

## 含まれるファイル

### 道路情報ファイル
- `roadic_kannetsu.csv` - 関越道のサンプル道路情報（15区間）
- `roadic_touhoku.csv` - 東北道のサンプル道路情報（11区間）

### 拥堵データファイル (processed_data/)
- `関越道_上_2025_05-19.csv` - 関越道上りのサンプル拥堵データ
- `関越道_下_2025_05-19.csv` - 関越道下りのサンプル拥堵データ
- `東北道_上_2025_05-19.csv` - 東北道上りのサンプル拥堵データ

## データの使用方法

### クイックテスト

```bash
# サンプルデータをdataディレクトリにコピー
cd workflow
cp -r sample_data/* data/
```

### テスト実行

```python
from workflow.test_complete_workflow import test_complete_workflow

result = test_complete_workflow(
    user_input="関越道2025年5月19日の交通拥堵状況を分析してください",
    ground_truth_file="data/processed_data/関越道_上_2025_05-19.csv"
)
```

## データフォーマット

### 道路情報 (roadic_*.csv)

| フィールド | 説明 | 例 |
|----------|------|-----|
| direction | 方向（上/下） | up, down |
| start_name | 区間開始地点 | 大泉ＪＣＴ |
| end_name | 区間終了地点 | 所沢 |
| KP | キロポスト | 2.48 |
| start_lat/lng | 開始地点座標 | 35.75582, 139.60151 |
| end_lat/lng | 終了地点座標 | 35.80615, 139.53551 |

### 拥堵データ (*.csv)

| フィールド | 説明 | 例 |
|----------|------|-----|
| date | 日付 | 2025-05-19 |
| 上下 | 方向 | 上 |
| 原因 | 拥堵原因 | 交通集中, 事故 |
| 道路番号 | 道路名 | 関越道 |
| 発生時刻 | 拥堵発生時刻 | 06:15:00 |
| ピーク時刻 | ピーク時刻 | 06:45:00 |
| ピーク長 | 最大拥堵長(km) | 8.5 |
| 発生Ｋｐ | 発生キロポスト | 0.0 |
| 発生時渋滞長 | 発生時拥堵長(km) | 2.1 |
| 渋滞時間 | 拥堵継続時間(分) | 120 |

## 注意事項

- これはテスト用サンプルデータです
- 実際の分析には реальные（実際の）道路データが必要です
- データ提供する際は、要件に応じたフォーマットで作成してください
